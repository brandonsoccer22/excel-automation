# Workbook automation

Use the [Excel object model](https://learn.microsoft.com/en-us/office/vba/api/overview/excel/object-model) and [xlwings API](https://docs.xlwings.org/en/stable/api/index.html). Keep Workbook, Worksheet, and Range references explicit. For COM members missing from the xlwings wrapper, use `.api` or pywin32 in the same Windows desktop session.

- **Files** — create with `app.books.add()` and open with `app.books.open(full_path, update_links=False, read_only=...)`. Check `FullName` and `ReadOnly` after opening. Use native `Save` for authorized in-place edits, `SaveAs` with explicit file format for format changes, and `SaveCopyAs` to retain the current workbook identity. Use the staging and collision checks in SKILL.md for new outputs. [SaveAs](https://learn.microsoft.com/en-us/office/vba/api/excel.workbook.saveas) · [SaveCopyAs](https://learn.microsoft.com/en-us/office/vba/api/excel.workbook.savecopyas)
- **Tables and formulas** — write rectangular values through xlwings and create or resize ListObjects over explicitly bounded ranges. Use `Formula2` for supported dynamic-array formulas and `Formula` for compatible ordinary formulas. Verify formulas as well as results, including spill dimensions, error cells and totals. Check `Application.CalculationState` after Excel recalculates. [ListObject](https://learn.microsoft.com/en-us/office/vba/api/excel.listobject) · [Formula2](https://learn.microsoft.com/en-us/office/vba/api/excel.range.formula2)
- **Names and connections** — use the owning workbook or worksheet's `Names` collection and qualified `RefersTo` expressions. Check name scope, references and collisions. Inventory `Workbook.Connections` by name, type and consumers before editing, refreshing or deleting. Avoid logging credential-bearing connection data. [Names](https://learn.microsoft.com/en-us/office/vba/api/excel.names) · [WorkbookConnection](https://learn.microsoft.com/en-us/office/vba/api/excel.workbookconnection)
- **PivotTables** — use `book.api.PivotCaches().Create(...)` with the appropriate source type, then `cache.CreatePivotTable(destination.api, name)`. For worksheet data use `xlDatabase` and a fully qualified source string or workbook table name. For model data use `xlExternal` and the workbook's `Model.DataModelConnection`. Set field orientations and aggregations explicitly. Model pivots use CubeFields and measures. Refresh and check totals against source data. [PivotCaches.Create](https://learn.microsoft.com/en-us/office/vba/api/excel.pivotcaches.create) · [Model.DataModelConnection](https://learn.microsoft.com/en-us/office/vba/api/excel.model.datamodelconnection)
- **Charts, slicers and dashboards** — create chart objects using xlwings or `Worksheet.ChartObjects().Add(...)` with explicit sources and sizes. Create a slicer cache with `Workbook.SlicerCaches.Add(pivot, field)` and a slicer with `cache.Slicers.Add(dashboard.api, ...)`. Link compatible pivots via `cache.PivotTables.AddPivotTable`. Use the correct hierarchy for model fields. Lay out on a dedicated sheet with explicit coordinates and inspect chart series, slicer connections, and filtered totals programmatically. [ChartObjects.Add](https://learn.microsoft.com/en-us/office/vba/api/excel.chartobjects.add) · [SlicerCaches.Add](https://learn.microsoft.com/en-us/office/vba/api/excel.slicercaches.add) · [Slicers.Add](https://learn.microsoft.com/en-us/office/vba/api/excel.slicers.add)
- **PDF** — set the requested print area and page setup, then call `Workbook.ExportAsFixedFormat(0, absolute_staging_path)` or the worksheet equivalent for single-sheet output. Publish to a fresh output path and verify the PDF opens and has the expected page count and content. [ExportAsFixedFormat](https://learn.microsoft.com/en-us/office/vba/api/excel.workbook.exportasfixedformat)
